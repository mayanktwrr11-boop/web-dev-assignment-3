# Portfolio 3 - HTML and CSS with Simple Effects

A portfolio based on the third expected-output reference. It uses beginner-friendly HTML and CSS, with a few small animations and hover effects.

## Concepts used
- Flexbox for arranging content
- CSS hover effect
- CSS transition
- Simple fade-in animation using `@keyframes`
- Smooth scrolling
- Media query for smaller screens

Open `index.html` in a browser. Keep `style.css` and `avatar.svg` in the same folder.
